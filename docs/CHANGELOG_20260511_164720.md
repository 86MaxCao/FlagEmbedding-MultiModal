# Changelog — 2026-05-11

## Summary

适配 `latest` 环境（transformers 5.8.0, torch 2.10.0+cu128），同时保持 `main` 环境（transformers 5.3.0, torch 2.7.1）向后兼容。

核心改动：将分散在各处的 transformers 5.8.0 兼容性补丁集中到 `FlagEmbedding/compat.py`，统一推理与训练代码的兼容性处理。

---

## New Files

### `FlagEmbedding/compat.py` (新增)
- 集中管理所有 transformers 5.8.0+ 兼容性 monkey patch
- 所有 patch 均为幂等（可安全重复调用）且向后兼容（在 5.3.0 下无影响）
- 提供的 patch：
  - `patch_qwen2vl_config()` — 在 `Qwen2VLConfig` 上暴露 `hidden_size` 属性（5.8.0 中该属性被移入 `text_config`）
  - `patch_identity()` — 给 `nn.Identity` 添加 `weight = nn.Parameter(torch.empty(0))`，避免 tie_weights 遍历模块时崩溃
  - `patch_tie_weights_for_meta_tensors()` — `torch.equal` 遇到 meta tensor 时返回 `False` 而非 `NotImplementedError`
  - `register_qwen3_vl_for_sequence_classification()` — 注册 `Qwen3VLConfig` 到 `MODEL_FOR_SEQUENCE_CLASSIFICATION_MAPPING`，使 `CrossEncoder` 可加载 Qwen3-VL 模型
- 提供三个聚合函数：`apply_jina_reranker_patches()` / `apply_qwen3_vl_reranker_patches()` / `apply_qwen3_vl_embedding_patches()`

### `FlagEmbedding/finetune/reranker/multimodal/qwen3_vl/` (新增，8 个文件)
- `__init__.py`, `__main__.py`, `arguments.py`, `load_model.py`, `modeling.py`, `dataset.py`, `trainer.py`, `runner.py`
- 完整的 Qwen3-VL-Reranker 训练管线
- 关键设计：
  - `modeling.py` 使用官方 Qwen3-VL-Reranker 评分机制：`base_model.last_hidden_state[:, -1] + score_linear(yes - no weights from lm_head)`，输出通过 `sigmoid` 得到 [0,1] 相关性分数
  - `load_model.py` 直接加载 `Qwen3VLForConditionalGeneration`（绕过 AutoModel 对 Qwen3VLConfig 的不支持）
  - `dataset.py` 使用 Qwen3VL 聊天模板格式（Instruct + Query + Document），支持 MegaPairs 和标准格式
  - 包含 `rope_deltas` 重置（防止 Qwen3VL batch-size mismatch bug）
  - 使用 `plain JSON` 加载、`use_fast=False` tokenizer、不传递 `processing_class` 给 Trainer（避免 C++ heap corruption）

### Test Files
- `verify_jina_reranker.py` — 交叉环境验证脚本，对比 main/latest 环境下 jina-reranker-m0 的推理分数
- `verify_output_5.3.0.json`, `verify_output_5.8.0.json` — 交叉环境验证结果

## Modified Files

### `FlagEmbedding/inference/reranker/multimodal/base.py`
- 移除内联 `_patch_qwen2vl_config` / `_patch_identity` / `_patch_tie_weights_for_meta_tensors`，改为从 `FlagEmbedding.compat` 导入
- `MultimodalReranker.__init__` 中：
  - `AutoModel.from_pretrained` 添加 `ignore_mismatched_sizes=True`（JinaVLForRanking 将 `lm_head` 替换为 `nn.Identity`，导致 checkpoint 中的 `lm_head.weight` 与 Identity 的 empty weight 尺寸不匹配）
  - 加载后重新赋值 `model.lm_head = nn.Identity()`，清除可能残留的 meta-device weight，使 `.to(device)` 正常工作

### `FlagEmbedding/inference/reranker/qwen3_vl_reranker.py`
- 移除内联 `_register_qwen3_vl_for_sequence_classification`，改为从 `FlagEmbedding.compat` 导入

### `FlagEmbedding/finetune/reranker/multimodal/jina_reranker_m0/load_model.py`
- 移除内联 `_patch_qwen2vl_config`，改为从 `FlagEmbedding.compat` 导入 `apply_jina_reranker_patches()`
- `get_model()` 和 `save_merged_model()` 中的 `AutoModel.from_pretrained` 均添加 `ignore_mismatched_sizes=True`
- `get_model()` 和 `save_merged_model()` 加载后添加 `lm_head` cleanup：`if isinstance(model.lm_head, nn.Identity): model.lm_head = nn.Identity()`
- 保留 `config.tie_word_embeddings = False`

### `FlagEmbedding/finetune/embedder/multimodal/qwen3_vl/load_model.py`
- 添加 `from FlagEmbedding.compat import apply_qwen3_vl_embedding_patches`，在模块导入时应用通用兼容性补丁

## Qwen3 Text Models (新增)

### `FlagEmbedding/inference/reranker/qwen3_reranker.py` (新增)
- `Qwen3Reranker` 推理类
- 基于 `AutoModelForCausalLM`（Qwen3ForCausalLM）
- 使用 Qwen3 聊天模板格式：
  - Prefix: `<|im_start|>system\nJudge whether...<|im_end|>\n<|im_start|>user\n`
  - Content: `<Instruct>: {}\n<Query>: {}\n<Document>: {}`
  - Suffix: `<|im_end|>\n<|im_start|>assistant\n<think>\n\n</think>\n\n`
- 分数计算：`logits[:, -1, :]` 在 `yes/no` token 位置取 `log_softmax`，返回 P(yes)
- 已注册到 `AUTO_RERANKER_MAPPING`：Qwen3-Reranker-0.6B/4B/8B

### `FlagEmbedding/finetune/reranker/decoder_only/qwen3/` (新增，8 个文件)
- `__init__.py`, `__main__.py`, `arguments.py`, `load_model.py`, `modeling.py`, `dataset.py`, `trainer.py`, `runner.py`
- `Qwen3RerankerModel`：encode 返回 `true_logits - false_logits`，支持 pairwise/listwise loss
- `Qwen3RerankerTrainDataset`：使用 Qwen3 聊天模板格式构造训练样本
- `Qwen3RerankerRunner`：tokenizer `use_fast=False`, `padding_side='left'`

### `FlagEmbedding/finetune/embedder/decoder_only/qwen3/` (新增，3 个文件)
- `__init__.py`, `__main__.py`, `runner.py`
- 复用 `decoder_only/base` 的 `BiDecoderOnlyEmbedderModel`（AutoModel + last_token pooling）
- `Qwen3EmbedderRunner`：tokenizer `use_fast=False`, `padding_side='left'`
- Qwen3-Embedding 训练入口：`python -m FlagEmbedding.finetune.embedder.decoder_only.qwen3`
